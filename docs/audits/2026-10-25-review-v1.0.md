# Review implementasi Agent Workflow

Tanggal: 25 Oktober 2026. Lingkup: skill, CLI, workflow_core, pengujian, serta integrasi portable. Review ini tidak mengubah kode produk.

## Temuan

### P1 — Cancel menghilangkan penghalang untuk hasil write yang belum diketahui

Lokasi: `workflow_core/engine.py:259–276`.

Reproduksi menggunakan Engine dan proyek sementara:

1. Buat task, pack, lalu `unknown` untuk write yang belum diketahui hasilnya.
2. `cancel` tanpa quiescent mengubah `blocked_outcome` menjadi `cancel_requested`.
3. `cancel --quiescent` kemudian berhasil menghasilkan `cancelled`, tanpa reconcile atau bukti.

Hasil aktual: `blocked_outcome → cancel_requested → cancelled`. Reservation output dilepas oleh Store.transition ketika cancelled. Task baru dapat mengambil output yang efek write lamanya belum direkonsiliasi. Ini bertentangan dengan aturan bahwa unknown outcomes harus direkonsiliasi sebelum replay.

Bahkan setelah langkah 2, `reconcile` menolak karena hanya menerima status `blocked_outcome`; jalur pemulihan resmi hilang.

Saran: simpan unresolved outcome terpisah dari status pembatalan, atau pertahankan blocked_outcome ketika cancellation diminta. Larang terminal cancellation dan pelepasan reservation selama unresolved outcome masih ada. Tambahkan regression test untuk unknown → cancel → reconcile serta unknown → cancel → cancel quiescent.

### P2 — read-output tidak menyediakan cara membaca seluruh isi baris panjang

Lokasi: `workflow_core/outputs.py:39–50`; opsi CLI `read-output` di `wf.py`.

Reproduksi: gunakan satu baris berisi 2.000 karakter A diikuti TAIL. `bounded_view(..., budget=6000, start=1, end=1)` mengembalikan hanya 700 karakter, `complete=false`, dan tanpa TAIL. Menaikkan budget tetap terkena batas 700 byte per baris. CLI tidak memiliki offset kolom atau cursor lanjutan.

`--find TAIL` bisa membaca jendela di sekitar teks yang sudah diketahui. Namun pengguna tidak dapat menelusuri seluruh bagian yang belum diketahui, dan pencarian berulang pada baris yang sama hanya memakai kecocokan pertama. Dampaknya terasa pada JSON minified dan log satu baris: bukti lengkap tersimpan, tetapi tidak seluruhnya dapat diambil melalui API skill.

Saran: tambahkan pagination kolom/byte dengan next cursor, atau mode baca rentang baris yang membagi baris panjang menjadi beberapa chunk. Pertahankan batas respons dan hash arsip. Tambahkan pengujian yang menyusun kembali seluruh baris dari beberapa retrieval tanpa membaca raw.txt langsung.

## Penilaian desain

Fondasi cocok untuk pendamping workflow dalam chat: transaksi SQLite menggabungkan state dan event; review mengikat hash output serta bukti; arsip output diverifikasi terhadap event; memory membedakan kutipan sumber dari fakta umum; skill menyatakan bahwa task bukan izin pengguna dan metrik byte bukan penghematan token.

Keterbatasan yang perlu dipertahankan dalam positioning: ini controller yang dipanggil secara kooperatif oleh agent, bukan enforcement atas semua tool native. Final review merupakan klaim chat dengan bukti, bukan review independen. Pilihan document/code/research/design disimpan sebagai label; implementasi tidak menyediakan executor atau pipeline domain terpisah. Penerimaan semantik tetap bergantung pada kualitas review agent.

## Validasi

- `python -m unittest discover -s tests -v`: 45 pengujian lulus, 13,313 detik.
- `python scripts/verify_portability.py`: lulus untuk workflow document dan code, copied kit, multi-folder, capture/retrieval, feedback, memory, revocation, dan backup di direktori sementara luar repository.
- Reproduksi tambahan melalui API Engine dan bounded_view mengonfirmasi dua temuan di atas. Fixture: `<temp>/wf-review-0y4dzyj4`.
- Dugaan bahwa koreksi review gagal pada output yang sama selalu ditolak tidak terkonfirmasi: failed review → passed review → verify berhasil completed. Tidak dimasukkan sebagai bug.

Rekomendasi: perbaiki P1 sebelum mengandalkan cancellation untuk pekerjaan dengan efek eksternal. Perbaiki P2 sebelum menjanjikan retrieval lengkap untuk semua output UTF-8. Suite yang hijau saat ini belum mencakup kedua kondisi tersebut. Tidak dilakukan audit keamanan menyeluruh atau pengujian semua interleaving concurrency.
